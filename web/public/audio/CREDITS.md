# Roast Court audio

Every sound effect is synthesized in the browser (`web/src/audio/sfx.ts`), so this folder can stay empty.

To use real recordings instead, drop files here and map them by name in `manifest.json`, e.g.

```json
{ "gavel": "gavel.mp3", "laugh": "crowd-laugh.mp3", "boo": "crowd-boo.mp3" }
```

Valid names: gavel, gavel3, sting, whoosh, ding, drumroll, scratch, ooh, boo, laugh, cheer, gasp, applause,
splat, slam, fanfare, trombone, pop, stamp, buzzer, tada, murmur.

Only add files you have the rights to (CC0 packs from kenney.nl or CC0-filtered freesound.org work well),
and credit them below.
